# Manuela Serrano Cegarra — Website

Static, responsive portfolio/consulting website built with plain HTML, CSS, and JavaScript. It can be hosted directly on GitHub Pages, Netlify, Vercel, or any static hosting provider.

## Repository structure

```text
manuela-serrano-website/
├── index.html
├── styles.css
├── script.js
├── README.md
└── assets/
    └── manuela-serrano.png
```

## Website details

The contact links are configured with Manuela's direct email and social profiles for the portfolio site.

You can also update the Open Graph image/title/description in the `<head>` section if needed.

## GitHub Pages

1. Create a new GitHub repository.
2. Upload every file and keep the `assets` folder intact.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder.
6. Save.

No build step is required.

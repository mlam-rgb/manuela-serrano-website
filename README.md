# Manuela Serrano Cegarra — Music Business Strategy Website

A responsive, professional music-business website built with plain HTML, CSS, and JavaScript. No build step is required.

The site positions Manuela as a music-business professional and creative strategist, with selected experience from RIMAS Entertainment, BMI Creative Latin, We Are Moving the Needle, Berklee Performance Center, ComunicARTE, live music projects, and international artist development.

## GitHub Pages

1. Create a new GitHub repository.
2. Upload all files and keep the `assets` folder intact.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder.
6. Save.

The site will work directly from the repository root.
